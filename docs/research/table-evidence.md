# OCR 表格证据与低 token 筛选

实施日期：2026-10-28。此模块只使用已获得的 OCR 文字和坐标，不调用模型、不下载权重、不运行表格识别网络。它为现有图片链路提供保守筛选，不把 OCR 行带当作经过验证的 HTML/Excel 单元格结构。

## 接口和预算

`src/fishkeeping/table_evidence.py` 提供：

```python
selection = select_table_evidence(regions, question, fits=fits_payload)
selected_regions = [regions[i] for i in selection.indices]
```

输入最多 256 个 `TextRegion`，索引始终指向调用方原始列表；允许输入未按坐标排序，但 region ID 必须唯一。`TableSelection` 返回选择索引、已保留的原子证据组、`requires_review`、警告和诊断。版本为 `ocr-table-row-context-v1`。

`fits_payload(indices)` 由调用方提供，应测量最终序列化 JSON 的字符预算，包含图片来源、selection 诊断等额外字段；不得用 OCR 正文字数代替整个 payload 大小。不提供回调时返回全部候选组。明确的简单查值使用 `selection_mode=target_rows`，每个候选组包含目标整行、推断表头、单位/脚注和紧邻的分组标题。预算只接受或拒绝整组，绝不逐格删数字、表头或单位；第二组超预算时可以保留完整第一组，但 `requires_review=true` 明确提示有遗漏。

问题范围或版面不确定时使用 `selection_mode=full_table_fallback`，所有输入 OCR 区域组成唯一原子组，包括同页其他表格。完整组超预算返回空 `indices/groups`、`dropped_groups=1` 和 `requires_review=true`；调用方应报告预算不足，要求更明确的区域或由调用方显式选择原生视觉，不能继续把局部命中当完整表格证据，也不会自动产生模型费用。

## 选择方法

1. 按文字框中心高度聚合近似行带，保留原文、负号、括号金额和坐标，不进行数字格式转换。
2. 使用“文本行标签后出现数字字段”的保守规则寻找数据行；通用列标题、纯年份行不作为数据行。首个候选数据行之前的全部行作为上方表头上下文，因此多行、分组表头及单位标题可以一起保留。
3. 问题词先使用项目共享的停用词规则，再去除少量表格问句填充词。表头词用于描述字段，剩余词定位具体数据行；保留匹配行的全部列，避免将同名年份、分组列或负数与错误表头拼接。
4. 非数据行中的单位、币种、数量级、来源和脚注标记作为全表上下文保留。目标行之前的连续非数据行也保留，帮助保留中途出现的分区标题和换行标签。
5. 只命中字段/表头、缺少查询术语、求和或比较、未建立表头/表体、重复行名或疑似跨行/重叠框时，都回退为完整 OCR 证据组并要求复核。数据候选行若是未知文本标签加至少两个 1900–2100 年份，也要求完整回退；例如 `State | 2023 | 2024` 不能因为标签不在通用表头词表中就被当作无关数据行删除。不会仅因某个 English 行名命中而裁掉跨语言问题的其他行，不翻译或补全未知术语，也不根据“最高相似度”猜测某条记录。

本轮优先从许多行中筛选少量目标行，不尝试激进裁掉目标行的其他列。这通常比保留整页所有数据行紧凑，也保留后续模型检查表头含义的必要证据；最终 token 节省必须通过实际提供商 usage 衡量。

## 明确的复核边界

- 没有建立带标签的数值表体，或表格第一条数据前没有可辨表头。
- 问题有未被 OCR 覆盖的词，不能确认所问字段存在；跨语言和同义词不会自动补全。
- 相同数据行标签出现多次：保留完整 OCR 证据，同时要求调用方明确地区、期间或币种。
- 文字框明显跨越多行，或同一行中列框重叠：不会声称恢复了合并单元格结构。
- 求和、比率、比较、变化等推导问题：需复核是否覆盖全部有关行列，不能把选中一条行当作完整计算证据。
- 选中区域置信度低于 0.75、某个完整证据组被预算排除或没有完整组能放入预算。

`structure_verified` 始终为 `false`。即便 `requires_review=false`，结果也只意味着这些启发式未发现问题，不保证原表真实、OCR 无误或所有隐含表头关系完整。单位/脚注采用词法标记；无标记的限定条件、跨页表格、竖排表头、列错位和复杂嵌套标题仍可能遗漏。图片处理层仍须把 OCR 截断、原图缩小和其他来源风险合并到最终复核标志。图中文字和表格脚注都是不可信证据，不能成为执行指令。
