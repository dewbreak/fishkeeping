# 独立时间线任务评测

2026-10-28，新建任务集，不读取用户数据库，不调用付费模型。先完成并冻结标签，再运行词法和当前本地混合配置；不据此改变阈值、查询或标签。此前两个检索集合已参与调参，本集合独立编写，但仍是人工合成诊断，不是用户流量样本或正式 benchmark。

冻结文件：[task_memory_cases.json](../../tests/fixtures/task_memory_cases.json)。初始文件字节 SHA256：`3ee36c6cc171a3f104c14494f3aa7bd0cf0d61056c65fb28975ac16ea5c86c11`。报告同时记录规范化 JSON SHA256，以便不同系统换行转换后仍能验证标签一致。此冻结记录写入时尚未执行任一后端评测。

8 个独立 scope 时间线包含偏好更新、无 `fact_key` 的矛盾、错误提取、改写、跨语言、空结果、scope/session 隔离、TTL、pinned 到期和来源删除。每一步依次执行真实 Store/MemoryService；本地模式在查询前明确补齐有效文档索引，查询自身不建立文档索引。这用于比较检索质量，不用于测自动索引工作流。

所有返回记录均有完整相关/无关标签，因此可以报告 Precision@k、Recall@k、MRR@k 和误召回。空结果不进入正例召回分母；误召回包括错误事实，生命周期/scope 禁止命中另行汇总。错误提取案例故意写入置信度 0.95 的错误金额，不把模型自报置信度当作事实验证。

最终回答仅测固定的“原文证据包”代理：保留召回记录中置信度 ≥ 0.7 的完整原文，按内容排序，无记录则返回 `INSUFFICIENT_EVIDENCE`，与手工预期证据集合精确比较。代理不读取 gold 标签来生成答案，不总结、推理或自动解决矛盾；没有真正调用 LLM，`llm_final_answer_accuracy` 为 null。这个指标只能发现证据遗漏/污染和低置信度弃答，不等于 DeepSeek 最终回答准确率。

成本记录实际付费调用数 0、API token 数 0、API 费用 US$0；本地模型编码次数单独统计。原文字符数不能冒充真实 tokenizer 用量。延迟包含真实 context 检索，但不含网络和 LLM；给出单次测量的中位数和最大值，不将小样本 p95 当生产 SLA。

## 冻结后的实际结果

规范化 JSON SHA256：`d3bd120dbb122a92610675c091e720f42a6841aa83ebfe8387808c20ce3f1175`。8 条时间线、21 次写入、25 个查询（16 正例、9 空结果）。两个报告均使用这个 hash；没有改动标签或调参。

| Recall@3 | 0.625000 | 0.906250 |

| 非空结果查询的宏平均 Precision@3 | 0.950000（10 查询） | 0.966667（15 查询） |
| 无关命中 / 总返回记录 | 1 / 15 | 1 / 20 |

| 付费调用 / API tokens / API 费用 | 0 / 0 / US$0 | 0 / 0 / US$0 |

Precision 的分母排除了无结果查询，因此必须与 Recall 和空结果一起阅读，不能只比较这一项。延迟为 Windows / Python 3.12.4、单进程、单次测量；本地权重预先缓存，无模型下载。查询延迟不包含显式索引和首次模型加载。

详细逐例结果：[词法](../evaluation-task-lexical-2026-10-28.json)、[本地混合](../evaluation-task-local-2026-10-28.json)。本地模式进行了 9 次文档编码批次（15 条文本）和 18 次查询编码；没有有效索引的空 scope 不需要编码问题。外部 scope 的干扰记录没有建立向量缓存，本集的跨 scope 向量泄露覆盖有限，生产边界仍由专门存储测试补充。

本地模式仍漏召回 `How do I get to the office?` 对应的折叠自行车通勤事实；`What is my work arrangement?` 只返回到办公室办公，漏掉同时有效的远程办公说法。这个部分召回意味着下游可能看不见矛盾，应保留该失败，而不能宣称自动处理了矛盾。

保留所有漏召回与已知错误提取，不修改标签以制造进步。无 `fact_key` 的矛盾仍需要调用方判断或补充明确更新指令，原文证据包不能自动决定哪条是真。高置信度错误提取仍可污染回答，需人工纠正或额外的来源一致性校验；删除错误记录后替换为正确事实、删除原始来源后级联去除派生事实的检查均通过。

## 复验

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_tasks.py --output .tmp/task-lexical.json
.\.venv\Scripts\python.exe scripts/evaluate_tasks.py --local-embeddings --output .tmp/task-local.json
.\.venv\Scripts\pytest.exe -q tests/test_task_evaluation.py --basetemp=.tmp/pytest-task-eval
```

本地命令强制 `HF_HUB_OFFLINE=1`；模型缓存缺失应报错，不下载、不退化成冒充本地模型的结果。普通 CI 可执行词法模式与 5 项离线测试，无网络、无 key 需求。冻结标签测试使用规范化 hash；新增题应另建版本，保留此集及历史报告。
